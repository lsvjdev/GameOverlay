Driver-provided interfaces

NVIDIA NVML is loaded from a compatible installed driver; it is not copied into the portable ZIP. Driver binaries have their own license terms.

The original .NET prototype

The stable main branch is an older, separate implementation. Its dependencies and third-party notices differ from the native C++ version.

Its original code is GPL-3.0-only. It also uses libraries such as LibreHardwareMonitor and transitive dependencies under their own licenses, and relies on a separately installed RTSS for in-game rendering.

Refer to the main-branch third-party notices and license collection for that implementation.

What ships with a build?

Native dev ZIPs include the relevant GPL text, applicable third-party licenses, and a corresponding-source notice inside bin/licenses. The application links to these files from its About page. This website is an easier-to-read companion, not a replacement for the license files supplied with binaries.

Before an official release, the distribution and source requirements will be reviewed against the exact set of bundled files. Any release should identify the source revision it was built from.

If you find an attribution issue, open a GitHub issue.
