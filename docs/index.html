02 / THE POINT

Built for the
corner of
your screen.

A performance readout shouldn't be another thing competing for your attention. Get the information you need, decide what shows up, then get back to playing.

01

Only what you choose.

Toggle and reorder FPS, system time, CPU, GPU, VRAM and RAM readings. CPU temperature and clock speed are displayed when the relevant sensors are available.

02

Two ways to disappear.

Use a compact dark strip or transparent text. Position it along the top or bottom of your screen, and set dark-strip opacity to suit your game.

03

No unnecessary company.

No account, ad panel, analytics or game booster. The native build uses Windows APIs and a small external FPS collector instead of a bundled .NET runtime.

04

Made to be inspected.

Source available on GitHub under GPL-3.0-only. Development happens publicly, with bugs and limitations documented rather than hidden behind a polished download button.

03 / UNDER THE HOOD

Small by design.
Not by omission.

The native build separates the overlay from the FPS collector and reads supported hardware sensors through native interfaces. No unnecessary monitoring history, and no background web service.

GameOverlayDev.exe

Overlay, local preferences, native settings window, CPU/RAM monitoring.

WINDOWS / C++
PresentMon

Frame presentation data via Windows ETW. Included in the native development package.

FPS COLLECTOR
Driver interfaces

NVIDIA NVML where supported; optional PawnIO for compatible AMD CPU temperatures.

OPTIONAL SENSORS
›_
Privacy is the default.

Preferences are saved locally. Game Overlay doesn't send your hardware readings to an online service. Diagnostics are copied only when you request them.

NOTE / The experimental collector runs as a second process. The native build has been tested in selected games, not every game or anti-cheat configuration. Hardware support varies.

04 / GET YOUR HANDS ON IT

It's a work
in progress.
Come look.

There isn't an official stable native release yet. The current C++ build lives on the dev branch, and testers can build it with the provided scripts. See the setup guide for dependencies, shortcuts and current limitations.
