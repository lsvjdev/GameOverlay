Before you start

Game Overlay's newer native C++ version is in active development. It has been tested on Windows in selected games, but compatibility and sensor availability can vary. There is currently no official stable native release on GitHub.

Two different app versions exist.

The older main branch contains the .NET / RTSS prototype. The dev branch contains the experimental native C++ version described here.

The native executable requests administrator privileges. Use only builds you trust and inspect the source if you want to understand how hardware access is handled.

Run the dev build

  1. Open the development branch on GitHub.
  2. On a Windows PC with Visual Studio 2022 C++ build tools, use native\build.cmd to build the executable. The AppVeyor project additionally assembles the portable ZIP with the supporting files.
  3. If you're using an AppVeyor artifact, extract the entire ZIP. Keep the bin directory beside the executable.
  4. Run GameOverlayDev.exe and accept the Windows UAC prompt if you trust the build.
  5. Double-click the tray icon to open settings, or right-click it for the menu.

AppVeyor artifacts are development build outputs, not signed consumer releases. We aren't offering a direct installer or public download button until the release process is ready.

How the pieces fit together

  • GameOverlayDev.exe draws the overlay and settings using native Windows APIs. The native build doesn't require .NET or RTSS.
  • PresentMon is the included frame collector needed for FPS readings. It runs as a separate process while the overlay is active.
  • NVIDIA NVML is provided by a compatible NVIDIA driver and used for supported GPU readings.
  • PawnIO must be installed separately for supported AMD CPU temperature readings. The ZIP includes an AMD sensor module, not the PawnIO driver or DLL.
  • License files are included for redistribution and are also accessible from the app's About section.

Without the supporting sensor components, some statistics may display --. The overlay and basic Windows metrics can still work.

Shortcuts

  • Ctrl + Shift + O : show or hide the overlay.
  • Ctrl + Shift + D : copy in-memory diagnostic details.
  • Ctrl + Shift + Q : exit the application.

Settings let you choose which metrics appear, reorder them, select a position and switch between dark-strip and transparent display styles.

When something reads --

FPS is missing

Check that PresentMon is inside bin, that the game window is active and that the game is producing supported frame presentation events. Press the diagnostic shortcut to see whether the collector started, detected the CSV header and matched the foreground process.

GPU temperature is missing

The first native GPU backend uses NVIDIA NVML. It isn't a universal GPU monitoring implementation, and individual readings depend on the graphics driver and hardware.

CPU temperature is missing

Supported AMD readings use PawnIO and the included sensor module. Administrator access alone isn't sufficient if the separately installed driver or library is missing.

Overlay appears over an ordinary application

“Only while gaming” currently checks FPS data and excludes some common desktop applications. It's a heuristic, not a definitive game detector, so false positives remain possible.

If you encounter a bug, please open a GitHub issue and include only the diagnostic information you're comfortable sharing.

What gets saved?

Preferences are stored locally at %LOCALAPPDATA%\GameOverlay\settings.ini. The app doesn't maintain a database of your game sessions, hardware readings or FPS history, and doesn't send telemetry to a remote server.

Diagnostic reports are generated in memory and copied to your clipboard only when you request them. The static website doesn't load an analytics SDK, cookies or external fonts either.
